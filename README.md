## 1. いま流行っているパーソナルAIアシスタント

### 2026年の流れ

2026年は「常駐型」が一気に広がった。2026年初めにオープンソースの OpenClaw が流行し、その後に大手各社が同じ型の製品を出した。

| 時期 | 出来事 |
|---|---|
| 2025-11 | オープンソースの常駐エージェント OpenClaw が公開される |
| 2026年初め | OpenClaw が流行する |
| 2026-02 | Hermes Agent が公開される。nanobot・NanoClaw・PicoClaw など、OpenClaw の軽量版も相次ぐ |
| 2026-03 | スマホから **Claude** に作業を任せる **Dispatch** |
| 2026-04 | **Claude Cowork** が一般提供。LINEヤフーの Agent i |
| 2026-05 | Google が **Gemini Spark** を発表 |
| 2026-06 | Microsoft Scout |
| 2026-07 | **ChatGPT Work**。**Gemini Spark** が日本語で使えるようになる |
| 2026-08 | **Claude in Chrome** が一般提供。Grok Bot のベータ |
| 2026-09 | Meta の **Muse** と OpenAI の **dots** |

### パーソナルAIアシスタントとは

質問に答えるだけでなく、利用者専用のエージェントとして次のことを行うもの。

- メール・カレンダー・ファイル・メッセージアプリにつながる
- 予定の調整、調べもの、返信の下書き、予約・購入などを自分から進める
- 好みや過去のやり取りを覚え、使うほど利用者に合っていく

### 分類

この資料では、次の7つの型で分ける。

| 型 | 動く場所・特徴 | 例 |
|---|---|---|
| 汎用アシスタント | アプリ・Web で会話する。大手のアプリは、常駐型やエージェント特化の機能を中に持つ | **ChatGPT**、**Gemini**、**Claude**、**Meta AI**、Microsoft Copilot |
| クラウド常駐型 | 提供元のクラウド。PC を閉じても動き続ける | **Gemini Spark**、**OpenAI dots**、**Meta Muse**、Microsoft Scout |
| エージェント特化 | 提供元のクラウドの仮想マシン。頼んだ作業を最後まで仕上げる | Genspark、Manus、**ChatGPT Work** |
| デスクトップ・ブラウザ型 | 手元の PC・ブラウザを操作する | **Claude Cowork**、**Claude in Chrome**、Perplexity Comet |
| セルフホスト型 | 自分の PC・VPS。チャットアプリから指示する | OpenClaw、Hermes Agent |
| 端末組み込み型 | スマホ・OS・スピーカー | Siri AI、Pixel の **Gemini**、Alexa+、Galaxy AI |
| ウェアラブル型 | メガネ・ペンダント・リング | Ray-Ban Meta、Plaud NotePin |

### 料金の見方

- 月額は月払いの金額、年額は年払いプランの1年分の金額。年払いの「月あたり」表示しかないものは12倍して載せている
- 年払いの無いものは「年払いなし」、公式に記載の無いものは「未確認」・「未公表」とした
- 円は日本の公式価格。ドルは米国での価格で、税は含まない

### 評判から見えること

- 上位は **ChatGPT**・**Gemini** の大手アプリに常駐型の機能（**dots**・**Spark**）が加わる形。単体の製品では Genspark・Manus（エージェント特化）と Plaud（録音・要約の端末）が、口コミの量・評価ともに目立つ
- 大手の常駐型（**Spark**・**dots**・**Muse**）は、始めてすぐの印象は良い一方、返信の遅さや使い込むまでの手間が不満に挙がる
- **Spark** は Google のサービスの中では強いが、それ以外とのつなぎ込みは弱い
- セルフホスト型は、安全面の不安から OpenClaw を離れて Hermes Agent に移る流れがある
- 国内企業のアプリ（Buffmee・Rakuten AI・ポケとも）は、評価件数が少なく星も 3 点前後にとどまる

## 3. 人気の製品の機能

### 機能の比較

人気の上位から、常駐型・エージェント型の8製品を選んで比べる。Plaud（録音の端末）と Grok・Perplexity（チャットが中心）は、比べる機能がほかと違うので外した。**dots** の値は報道による。2026-10-03 時点。

| 製品 | 動く場所 | 頼み方 | つながるサービス | 自分から動く | Web の操作 | 手元の PC・ファイル | 記憶・スキル | 日本 | 月額 |
|---|---|---|---|---|---|---|---|---|---|
| **OpenAI dots** | クラウド（専用のクラウド PC。常時動く） | **ChatGPT** のアプリ・Web、Slack、Teams | 4,000以上のアプリ（Google ドライブ・メールなど） | 動く（定期実行・きっかけで起動・先回りの調査） | できる（専用のブラウザ） | 許可すれば手元の PC につなげる | 好みや経緯を覚える。スキルの保存は未確認 | ✅ **利用可** | Pro 16,800円〜 |
| **Gemini Spark** | クラウド（Google Cloud の専用 VM。24時間動く） | **Gemini** アプリ、専用の Gmail アドレス | Workspace（Gmail など） | 動く（決まった時刻・メールの受信で起動） | できる（Google 以外は画面を読み取って操作） | できない | 自分用のスキルを作れる | ✅ **利用可** | AI Pro 2,900円〜 |
| **Meta Muse** | クラウド（専用の VM。アプリを閉じても動く） | **Muse** のアプリ・Web、WhatsApp | 利用者が選んだアプリ（メール・買い物・旅行の予約など） | 頼まれなくても提案する。定期実行は未確認 | できる（専用のブラウザでフォームに入力） | 未確認 | 大事なことを覚え、「忘れて」で消せる。スキルは未確認 | ❌ **不可** | 無料枠あり<br>Power 20ドル〜 |

### 製品ごとの評判

| 製品 | 良い声 | 不満・注意の声 |
|---|---|---|
| **Gemini Spark** | 毎朝の定時やメールの受信をきっかけに自動で動き、PC やスマホの電源を切っていても進む。教員の実例では、LINE・GAS と組み合わせて授業準備が週30分〜2時間からほぼ0分になった | 自分の PC の画面やローカルのファイルは操作できない。Google 以外のサービスとは画面を読み取って操作する形になる。仕事用・学校用のアカウントでは使えず、教員が仕事で使える形ではまだないという声 |
| **ChatGPT** **dots** | 「1時間触って手放せない」。Google ドライブや Slack の接続がクリックだけで済む。ペットの姿のキャラクターに愛着がわく。会話していない間も先回りして提案が出る | Slack での返信に約3分かかり、リアルタイムの用途には向かない。届いたかどうかが分かりにくい。音声通話は応答をかなり待つ。使い込むまでが不便で、最初に慣れる前にやめてしまいやすい |
| **Meta Muse** | 試したパーソナルエージェントの中で最も使い勝手の設計が良いという評。家族の予定から朝の案内 PDF を一度で作った。許可の仕組みがほかと違って分かりやすい | 渡すデータが多いほど便利になる反面「便利で怖い」（WSJ）。日本では使えない |
| **Claude Cowork** | フォルダの整理や名刺からのデータ抽出など、定型作業の時短になる。スキルを作って保存すると便利になる | 料金と使用量の制限、セキュリティや誤操作を心配する声 |
| Hermes Agent | Reddit で最も勧められるセルフホスト型。使うほど自分で賢くなる。OpenClaw から設定・記憶・スキルを移せる | 導入と保守に技術の知識が要る。定時実行（cron）や中継部分（ゲートウェイ）が壊れるという報告 |
| OpenClaw | 導入事例・解説記事が最も多い | Reddit ではシェル操作や平文の API キーなど安全面の話題が中心で、代わりを探すスレッドが多い。国内でも Hermes Agent への乗り換えの報告がある |
| Genspark | ITreview の平均 4.2／5。目的がはっきりしている人には強力。資料作成の時短 | クレジットの消費が多い。目的があいまいだと評価が割れる |
| Manus | 手放しで何段階もの作業を最後まで実行する | プライバシーの懸念が Reddit でよく挙がる |
| Lindy | メールとカレンダーの扱いが洗練されている | できる範囲が狭い |
