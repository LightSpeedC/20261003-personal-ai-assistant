いま流行っているパーソナルAIアシスタント

2026年の流れ

2026年は「常駐型」が一気に広がった。2026年初めにオープンソースの OpenClaw が流行し、その後に大手各社が同じ型の製品を出した。

パーソナルAIアシスタントとは

質問に答えるだけでなく、利用者専用のエージェントとして次のことを行うもの。

  • メール・カレンダー・ファイル・メッセージアプリにつながる
  • 予定の調整、調べもの、返信の下書き、予約・購入などを自分から進める
  • 好みや過去のやり取りを覚え、使うほど利用者に合っていく

分類

この資料では、次の7つの型で分ける。

型動く場所・特徴例
汎用アシスタントアプリ・Web で会話する。大手のアプリは、常駐型やエージェント特化の機能を中に持つChatGPT、Gemini、Claude、Meta AI、Microsoft Copilot
クラウド常駐型提供元のクラウド。PC を閉じても動き続けるGemini Spark、OpenAI dots、Meta Muse、Microsoft Scout
エージェント特化提供元のクラウドの仮想マシン。頼んだ作業を最後まで仕上げるGenspark、Manus、ChatGPT Work

料金の見方

  • 月額は月払いの金額、年額は年払いプランの1年分の金額。年払いの「月あたり」表示しかないものは12倍して載せている
  • 年払いの無いものは「年払いなし」、公式に記載の無いものは「未確認」・「未公表」とした
  • 円は日本の公式価格。ドルは米国での価格で、税は含まない

評判から見えること

  • 上位は ChatGPT・Gemini の大手アプリに常駐型の機能（dots・Spark）が加わる形。単体の製品では Genspark・Manus（エージェント特化）と Plaud（録音・要約の端末）が、口コミの量・評価ともに目立つ
  • 大手の常駐型（Spark・dots・Muse）は、始めてすぐの印象は良い一方、返信の遅さや使い込むまでの手間が不満に挙がる
  • Spark は Google のサービスの中では強いが、それ以外とのつなぎ込みは弱い
  • セルフホスト型は、安全面の不安から OpenClaw を離れて Hermes Agent に移る流れがある
  • 国内企業のアプリ（Buffmee・Rakuten AI・ポケとも）は、評価件数が少なく星も 3 点前後にとどまる

製品ごとの評判

製品良い声不満・注意の声
Gemini Spark毎朝の定時やメールの受信をきっかけに自動で動き、PC やスマホの電源を切っていても進む。教員の実例では、LINE・GAS と組み合わせて授業準備が週30分〜2時間からほぼ0分になった自分の PC の画面やローカルのファイルは操作できない。Google 以外のサービスとは画面を読み取って操作する形になる。仕事用・学校用のアカウントでは使えず、教員が仕事で使える形ではまだないという声
ChatGPT dots「1時間触って手放せない」。Google ドライブや Slack の接続がクリックだけで済む。ペットの姿のキャラクターに愛着がわく。会話していない間も先回りして提案が出るSlack での返信に約3分かかり、リアルタイムの用途には向かない。届いたかどうかが分かりにくい。音声通話は応答をかなり待つ。使い込むまでが不便で、最初に慣れる前にやめてしまいやすい
Meta Muse試したパーソナルエージェントの中で最も使い勝手の設計が良いという評。家族の予定から朝の案内 PDF を一度で作った。許可の仕組みがほかと違って分かりやすい渡すデータが多いほど便利になる反面「便利で怖い」（WSJ）。日本では使えない
Claude Coworkフォルダの整理や名刺からのデータ抽出など、定型作業の時短になる。スキルを作って保存すると便利になる料金と使用量の制限、セキュリティや誤操作を心配する声
Hermes AgentReddit で最も勧められるセルフホスト型。使うほど自分で賢くなる。OpenClaw から設定・記憶・スキルを移せる導入と保守に技術の知識が要る。定時実行（cron）や中継部分（ゲートウェイ）が壊れるという報告
OpenClaw導入事例・解説記事が最も多いReddit ではシェル操作や平文の API キーなど安全面の話題が中心で、代わりを探すスレッドが多い。国内でも Hermes Agent への乗り換えの報告がある
GensparkITreview の平均 4.2／5。目的がはっきりしている人には強力。資料作成の時短クレジットの消費が多い。目的があいまいだと評価が割れる
Manus手放しで何段階もの作業を最後まで実行するプライバシーの懸念が Reddit でよく挙がる
Lindyメールとカレンダーの扱いが洗練されているできる範囲が狭い
